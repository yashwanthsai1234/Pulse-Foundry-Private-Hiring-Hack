# A2 research notes: PDF cascade, legend, shift grammar

Experiments and numbers: `docs/pdf_spike.md`.

## Sources and what each decided

- https://github.com/jsvine/pdfplumber (table extraction settings): lines vs text strategies, `snap_tolerance` / `join_tolerance`
  (default 3), `extract_words(extra_attrs=["size"])`. Decided the settings of methods 1 and 4 and the font-size based context rules.
  The README names Anssi Nurminen's thesis as the basis of the algorithm.
- https://pymupdf.readthedocs.io/en/latest/page.html (Page.find_tables): returns `tables`; each has `rows[i].cells`, `extract()`.
  Decided method 3 (`pdf.mupdf`) and how cell bboxes are read. Sniff uses `Page.get_text()`.
- https://pymupdf.readthedocs.io/en/latest/pixmap.html: `get_pixmap(dpi=150)`; also used to build the `raster_150dpi` test PDF
  (`insert_image`) and to open PNG/JPEG as one-page documents in the scan parser.
- https://github.com/camelot-dev/camelot (Lattice for ruled tables, Stream for whitespace tables; also web search results on Camelot):
  confirmed the two-family split (ruling lines vs text alignment) and the idea of a per-table quality score. Our cascade is
  that split plus an own word-clustering method.
- https://trepo.tuni.fi/handle/123456789/21520 (Nurminen 2013, "Algorithmic extraction of data in tables in PDF documents"):
  row/column structure from word boxes without ruling lines. Idea behind `pdf.words` (rows by y, columns from x corridors).
- https://doi.org/10.1109/ICDAR.2013.292 (Goebel et al., ICDAR 2013 Table Competition): table structure is evaluated by comparing
  cells with ground truth. Decided the spike metric (cell-by-cell accuracy).
- https://docs.reportlab.com/reportlab/userguide/ch7_tables/: Table/TableStyle for the renderer variants (SPAN for the merged
  header, colWidths + Paragraph cells for wrapped names).
- https://docs.python.org/3/library/re.html: grammar regex shared by `shifts.py` and `legend.py`.

Not reachable: the Camelot "how it works" and "advanced" pages on readthedocs returned 404 when fetched, so they are not cited.
