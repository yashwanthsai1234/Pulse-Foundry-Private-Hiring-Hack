Design notes
- Defects are plain functions on a deep copy of the world; each test asserts the exact set of files that changed (hr, payroll, licenses, schedule.json).
- `missing_rn_day` runs last and RN shifts use day tokens only, so removing RN shifts on one day really leaves a gap (a 11p-7a night shift would cover the next day under the "overlaps the day" rule).
- Date mutators rewrite a column only if some day > 12, so the new format stays inferable and semantics do not change.
- `drop_optional_column` loses data on purpose; chaos ignores phone/hire_date/last_verified in the golden comparison when it ran.
- as_of for a world = day after the schedule ends (start + 7*weeks); chaos passes it to the pipeline settings.
