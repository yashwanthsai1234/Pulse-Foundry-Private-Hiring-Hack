# A1 research: sniff auction and tabular parsers

## Sources
- https://duckdb.org/2023/10/27/csv-sniffer.html : delimiter = most columns with most consistent rows; header = first row whose types differ from the data below. Drove the delimiter score (modal field count share, ties broken by wider) and the header test.
- https://arxiv.org/abs/1811.11242 (CleverCSV) : row-shape consistency beats csv.Sniffer by ~22% on messy files. Confirms not using csv.Sniffer.
- https://charset-normalizer.readthedocs.io/en/latest/ : `from_bytes(...).best()`; kept only as the last fallback.
- https://github.com/dimastbk/python-calamine : `load_workbook`, `to_python(skip_empty_area=False)` keeps true row numbers.
- https://docs.pola.rs/api/python/stable/reference/api/polars.json_normalize.html : considered for JSON, not used.

## Experiments (200k rows, 5 cols, quoted names)
- Polars read_csv (all Utf8): 0.016 s. stdlib csv.reader: 0.10 s. Full CsvParser.extract incl. header detection and build: 0.36 s (limit 5 s).
  Chose stdlib csv: Polars gives no source line numbers, and `_src_row` must be the true line (multi-line quoted fields shift it; tested).
- csv.Sniffer on a file with 3 title rows then a `;` header: raises "Could not determine delimiter". Own consistency vote handles it.
- charset-normalizer on short latin-1 text ("José,Bogotá / Zoë,Köln"): returned cp1250 (wrong for Western accents). Now: BOM, then strict UTF-8 (incremental, tolerates a cut tail), then cp1252, then charset-normalizer (Shift-JIS test passes via it).
- pl.json_normalize handles mixed types but returns typed columns (i64, list, floats), needing a per-column cast to text; own 6-line flatten gives text directly.
- python-calamine opens an .xlsx saved as .csv by path (format detected from content), so no BytesIO workaround.

## Deviations from the spec
- Header detection fallback: spec says row 0; implemented as the first row at least half the modal width (row 0 when none). Reason: all-text tables under a title row would otherwise pick the title. Tested.
- CSV sniff rejects text starting with `{` or `[` (JSON could otherwise score CSV 1.0 > JSON 0.95 for compact NDJSON).
- Auction catches a sniff exception and records score 0 so one broken parser does not block the file.
- Files > 200 MB streaming to Parquet (§8.2) not implemented (not needed for the hackathon data).
