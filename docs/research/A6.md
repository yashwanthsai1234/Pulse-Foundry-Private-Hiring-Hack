# A6 research notes: agent gateway, orchestrator, API

Sources and what each decided:

- https://code.claude.com/docs/en/headless : `claude -p` with `--output-format json --json-schema` returns the schema-checked object in `structured_output` of the JSON envelope; `--bare` skips login/keychain so it is not used. Decided the ClaudeCliExecutor command and parsing.
- https://code.claude.com/docs/en/cli-reference : `--tools`, `--no-session-persistence`, `--max-budget-usd` flags used verbatim.
- https://github.com/sysid/sse-starlette : `EventSourceResponse` over an async generator of `{"event","data"}` dicts; decided sse.py (replay then live, end on run.completed/failed).
- https://fastapi.tiangolo.com/advanced/events/ : lifespan context manager owns the 1 s agent-result poller task.
- https://fastapi.tiangolo.com/tutorial/background-tasks/ : sync callables run in the thread pool, so `Pipeline.ingest` runs off the event loop via `BackgroundTasks`.
- https://docs.python.org/3/library/asyncio-eventloop.html#asyncio.loop.call_soon_threadsafe : asyncio.Queue is not thread-safe; EventBus stores (loop, queue) per subscriber and delivers with call_soon_threadsafe.
- https://docs.python.org/3/library/asyncio-task.html#asyncio.run_coroutine_threadsafe and #asyncio.to_thread : background executors (claude -p) are scheduled on the API loop from the pipeline thread; the poller calls `poll_agents` in a thread so on_accept may run the synchronous pipeline.
- https://python-jsonschema.readthedocs.io/en/stable/validate/ : `Draft202012Validator.iter_errors` gives all schema errors as rejection notes.
- https://pymupdf.readthedocs.io/en/latest/page.html#Page.get_pixmap and /rect.html : clip + dpi=144 for the evidence crop; `Rect.intersect` keeps the clip on the page.

Decisions and evidence

- Executors all write `pending/<id>.json`; the gateway reads the task back from there in `poll()`.
- `submit()` rebuilds the task with `make_task`, so the PDF scan parser (A2) may pass a bare AgentTask.
- Starlette form parts are `starlette.datastructures.UploadFile`, not `fastapi.UploadFile`: `isinstance` with the FastAPI class returned 0 uploads (found by the failing ingest test). The endpoint therefore accepts any file part name (`files`, `files[]`).
- Agent results arriving during ingest are applied without a nested rebuild (`_batch` flag); the final stage 5-7 pass covers them.
- Cache hits for identity adjudication re-run resolve once (max 2 passes), so a cached "same" takes effect in the same run.
