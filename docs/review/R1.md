## Observed but not turned into tests (lower confidence / design)
- api/routes_data.py `/shifts` `license_valid`: true if the person holds ANY unexpired credential, even of a type that does not cover the shift role (LIC-SCOPE says otherwise). Display only.
- Facilities/roles vocab only knows BAY/RVD and RN/LPN/CNA: any unseen facility yields unknown_vocab + ROW-INCOMPLETE; a PDF schedule page whose title does not match a facility gets `facility_id NULL` shifts that COV-RN-DAILY / FAC-MISMATCH silently skip (no issue says "facility not resolved").
- api/routes_ingest.py: `GET /runs/{id}/events` returns 404 until the background task inserts the run row (UI uses the global stream, so low impact).
- Pipeline `_anchors()` is evaluated at silver time; changing as_of later does not re-date schedules that fell back to as_of.
- COV-RN-DAILY assumes Mon-Sun weeks around the shifts (known, B-008).
