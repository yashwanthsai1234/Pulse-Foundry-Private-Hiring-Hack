# B2 - Edge-case attacker (ingestion -> mapping -> normalization -> resolution -> checks)

Method: judge-style messy inputs written to `tmp_path`, run through the real `Pipeline(settings).ingest(...)` (agents off, `as_of` 2026-09-21).
Harness: `backend/tests/breakers/edge_world.py` (4-person baseline: 3 CSVs + a 2-page PDF made with `tools/synth/render.py`).
Tests: `backend/tests/breakers/test_edge_{licenses,names,facilities_roles,dates,payroll,hr,schedule,files}.py`. Each test is one attack asserting the CORRECT behaviour, so a failing test is the evidence. Run: `cd backend && .venv/bin/python -m pytest tests/breakers/test_edge_*.py`.
Severity: CRITICAL = crash or silent wrong/lost data; HIGH = wrong data that is only weakly flagged, or a whole file lost; MEDIUM = under-flagged; LOW = noise.
Not re-reported (already in BREAKDOWNS.md): B-002, B-004, B-007, B-012, B-019.

## What held up (passing tests)
Facility spellings (Bayside, HV-Bayside, Harborview Bayside SNF, BAYSIDE, payroll bys/BYS), role spellings (R.N., CNA II, LPN/LVN, Registered Nurse (RN)), Sofia/Sofía/SOFIA/Reyes, Sofia M./Reyes S. via payroll+schedule, maiden name with a shared licence number, swapped first/last HR columns, two same-name employees at two facilities, J. Smith with two candidates (ID-AMBIGUOUS, not guessed), HR duplicate ids (HR-DUP-ROW), ID-DUP-LICENSE, BOM/CRLF/semicolon/tab/title lines, blank rows, trailing spaces, extra/missing columns, empty/garbage/.txt/JSON/XLSX files, native Excel dates, Excel serial / `2026-9-4` / `Sep 14, 2026` / `14-Sep-2026` columns, overnight Sunday shift, same person on both pages (SHIFT-OVERLAP), legend contradiction (LEGEND-MISMATCH), CNA scheduled as RN (LIC-SCOPE), 40 rows per page spill (all shifts kept), unknown shift tokens `D`/`N`/`8-4` (PARSE-SHIFT-TOKEN).

## Notes on evidence
- Crash traces: `_duckdb.ConstraintException ... pay_id: P-3001` (B2-01) and `KeyError: 'pay.period_start'` at `sot/truth/gold.py:75` (B2-02) both propagate out of `Pipeline.ingest` (run marked failed, nothing usable for the judge).
- Mapper evidence for B2-04/05/06: `SELECT * FROM mappings` rows (`hr_roster 0.8 mapped`, `license 0.95 mapped (drift)`, `license 0.75 pending_agent`).
- Date matrix: 12 whole-file styles, 6 fail (B2-06). US `MM/DD` columns are read month-first and flagged PARSE-DATE-AMBIGUOUS only when every value is <= 12 (works as designed).
