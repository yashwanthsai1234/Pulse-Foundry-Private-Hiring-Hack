# B1 - wiring audit (W3-B1)

Method: real uvicorn (`SOT_AGENTS=queue`, tmp runtime) + `npm run build` dist + real Chrome via playwright-core (Chrome was installed; playwright-core installs in 1 s, no browser download). Fixture: `example_e1`. The frontend `npm test -- --run` passes (18 tests, all on mock data). Tests: `backend/tests/breakers/test_wiring_api.py`, `test_wiring_agents.py` (helpers `wiring_support.py`, `shapecheck.py`). Failing tests = evidence.

## What works (verified with real data)
- All 4 e1 files ingest; SSE delivers 28 events, ordered, replay after completion works, page reload replays the latest run in Chrome.
- Every endpoint of section 17 matches `frontend/src/api/types.ts` field by field (names, types, nullability): **no shape mismatches** (`test_every_endpoint_matches_frontend_types` passes). Event `data` keys the UI reads (`parser,score,bids`; `table_id,method,score,rows`; `table_id,template_id,confidence,matches,unmapped_columns`) are emitted for sniffed/extracted/mapped/unmapped.
- Evidence crop: PNG, `X-Highlight` in 0..1, and the highlighted region extracted with pymupdf contains the shift text (`3p-11p`) for all 4 LIC-WORKED-EXPIRED cells; Chrome renders crop + highlight overlay.
- PATCH acknowledged survives re-ingest (first_seen kept, last_seen bumped); PUT as_of 2027-05-10 creates LIC-EXPIRING (HIGH, Sofia Reyes), going back deactivates it.
- Agent queue: a vendor file with non-matching headers creates a pending `schema_mapper` task; a valid `done/<id>.json` is accepted by the poller, re-runs, LIC-EXPIRING for the vendor (12 days) appears with no restart. Schema violation and validator violation both give a HIGH AGENT-REJECTED issue with the agent output as evidence. A vendor file with matching headers auto-maps as `vendor_credential` (1.00) and gives LIC-EXPIRING directly. page_reader tasks for a scanned PDF were accepted and applied.
- Two concurrent ingests are serialized by the pipeline lock and both complete.
