# B4 - chaos root causes and simplicity audit (breaker W3-B4)

Scope: (1) classify every miss and every unmatched issue of the chaos runner into root causes; (2) simplicity and dead-code audit of `backend/sot`, `backend/tools`, `backend/packs/*/checks`, `frontend/src`.
Nothing in `sot/`, `packs/`, `tools/` or `frontend/src/` was touched. Written: this file and `backend/tests/breakers/test_chaos_rootcauses.py` (22 tests, all red today, each names the cause it reproduces; run `cd backend && .venv/bin/python -m pytest tests/breakers/test_chaos_rootcauses.py`).

## 1. Chaos summary

`python -m tools.synth.chaos --n 30 --seed S --out /tmp/chaosX`. To separate "the system is wrong" from "the mutation broke it", I re-ran every variant twice (clean files vs mutated files, same expectations), then single-factor runs (one mutator on one file of a fixed world), per-file mapping scans of all 180 mutated files, a header-synonym sweep, and per-variant PDF-variant renders. Scratch scripts: the session scratchpad (`deep.py`, `single.py`, `filemaps.py`, `syn.py`, `pdfs.py`).

| Run | recall | precision | golden equality | expected / matched / reported-as-checked |
|---|---|---|---|---|
| baseline `--n 5 --seed 7` (given) | 81.7% | 34.0% | 60% | - |
| `--n 30 --seed 11` mutated | 73.4% | 29.1% | 26.7% (8/30) | 353 / 259 / 891 |
| `--n 30 --seed 11` clean files (no mutation) | 80.5% | 38.6% | n/a | 353 / 284 / 735 |
| `--n 30 --seed 23` mutated | 59.2% | 24.2% | 16.7% (5/30) | 422 / 250 / 1035 |
| `--n 30 --seed 23` clean files | 79.4% | 48.1% | n/a | 422 / 335 / 697 |

Reading: even with NO mutation, recall is ~80% and precision ~40%: about three quarters of the miss and the false positives are not caused by format chaos at all. They come from (i) naming/contract mismatches between the checks and the harness and (ii) generator/matcher limitations. The mutations add (a) real parser/mapping bugs (licence file mapped to `vendor_credential`, header misdetection, latin-1 garbling) and (b) PDF variants that the harness cannot satisfy with agents off.
